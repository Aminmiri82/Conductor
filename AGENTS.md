# Conductor

Ultra-lightweight, fast Postman alternative. Optimize for speed and low memory.

**Stack:** Tauri 2, SQLite, Rust, React, Zustand.

**Goal:** Broad Postman collection compatibility. Design for efficiency; pre-production—no need to preserve backwards compatibility(this includes the database schema, no need for migrations).

**Git:** Do not commit or push without Yara’s explicit approval.
